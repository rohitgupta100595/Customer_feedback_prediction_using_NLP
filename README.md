# Customer Feedback Prediction Using NLP
This project predicts the customer feedback type (Positive / Negative) using Natural Language Processing.

## Objective
Build a Machine Learning pipeline that automatically predicts the sentiment of a customer complaint.

## Approach
- Data Cleaning and Validation
- Exploratory Data Analysis
- TF-IDF feature extraction
- Logistic Regression classifiaction
- Model evaluation
- Model deployment using streamlit

## Final Deliverable
A trained NLP pipeline saved as pipeline.pkl and integrated into a streamlit application for real-time sentiment prediction.
